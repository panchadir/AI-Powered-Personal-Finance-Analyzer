## Deferred from: one-shot spec-1-4-database-url-fallback (2026-07-09)

- ~~**`docker-entrypoint.sh` DSN parsing is fragile (pre-existing; surfaced by Blind Hunter, not caused by the fallback change).** The Postgres-wait probe parses `DATABASE_URL` with `re.match(r".*://([^:]+):([^@]+)@([^:/]+)(?::(\d+))?/(.+)", url)`; a password containing `@`/`:`/`/` mis-parses, and any URL the regex can't match makes `m` `None` → `AttributeError` instead of a clear message.
