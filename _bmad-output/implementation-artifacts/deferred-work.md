AD-5 should be amended (or annotated) to reflect the Phase-1 SameSite-cookie baseline vs the Phase-2 httpOnly target. Consider a `correct-course` pass to formally reconcile the AD text.
- **Vestigial `_auth_token` localStorage slot from reflex-local-auth's unused `LocalAuthState` (Story 1.3, AC #3 partial).** Our real token is a SameSite cookie owned by `finance_app.state.auth_state.AuthState` (verified at `reflex run`: compiled `clientStorage.cookies` carries `_auth_token` with `sameSite=strict`). ## Deferred from: one-shot spec-1-4-database-url-fallback (2026-07-09)

- **`docker-entrypoint.sh` DSN parsing is fragile (pre-existing; surfaced by Blind Hunter, not caused by the fallback change).** The Postgres-wait probe parses `DATABASE_URL` with `re.match(r".*://([^:]+):([^@]+)@([^:/]+)(?::(\d+))?/(.+)", url)`; a password containing `@`/`:`/`/` mis-parses, and any URL the regex can't match makes `m` `None` → `AttributeError` instead of a clear message. Only runs in-container so severity is low today (creds are the known compose values), but harden it (parse with `sqlalchemy.engine.make_url` / `urllib.parse`, and fail with a readable message) when entrypoint work is next touched. Source: adversarial review of the `DATABASE_URL` fallback change.
