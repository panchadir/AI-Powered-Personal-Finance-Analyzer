- (constraint) PRD finalized 2026-07-08 (status: final); all decisions in PRD §11 are ADOPTED — spine inherits them, does not re-derive
- (constraint) 3-day solo build, local-only, single-user; no cloud infra, no TLS, no multi-tenant — scope boundary for all deferred items
- (decision) AD-1: engine/narrate hard boundary — services/engine/ (deterministic math) and services/narrate/ (LLM language) must never import each other; LLM is structurally excluded from STS/CS computation; prevents LLM inventing financial figures with no audit trail
- (decision) AD-2: service layer framework-agnosticism — all business logic in services/{ingestion,categorize,engine,narrate}/; rx.State handlers call service functions only, contain no logic; if the Reflex app dir were deleted, services/ must be independently runnable and testable; makes Phase 2 FastAPI split a re-skin not rewrite
- (decision) AD-3: single state-mutation path — financial state (STS, CS, commitments, transactions) is mutated only by services/ functions; rx.State reads the result; prevents two UI handlers computing different STS figures from the same data
- (decision) AD-4: user_id data isolation — every DB query (read and write) must include a user_id WHERE clause; no query may return rows belonging to another user; enforced by a test (cross-user isolation); prevents IDOR into Phase 2 per FR-1.4
- (decision) AD-5: auth token in httpOnly cookie only — never localStorage, never a custom header for MVP session; prevents XSS token theft; DPDP compliance baseline per FR-1.1, NFR-5
- (decision) AD-6: canonical transaction schema ownership — all parsers normalize to one canonical Transaction shape before persistence; no parser-specific shape crosses the ingestion boundary; prevents two parsers creating incompatible row shapes in the DB
- (decision) AD-7: category enum hard-constraint — Tier-2 LLM categorization uses a fixed enum via messages.parse() / structured output; no free-text category may be stored; dual purpose: prevents invented categories and blocks prompt injection via hostile merchant strings per S3.2
- (decision) AD-8: STS floor and conservative rounding — safe_to_spend_today = max(0, (balance - reserved_total - buffer) / days_to_income); always floored to ₹0 (max guard); always rounded down to nearest ₹10 (never up); prevents any displayed STS figure causing a missed committed obligation — the kill-signal surface per NFR-1, FR-4.1
- (decision) AD-9: score_events as score write path — Confidence Score is only emitted alongside a score_events row (delta, triggering_event, explanation, suggested_action); the UI renders score from the event log; an unexplained score change is structurally impossible per FR-5.3
- (decision) AD-10: Copilot read-only tool contract — the Copilot LLM is given read-only tools only (get_safe_to_spend, get_confidence_score, query_transactions, get_spending_by_category, get_upcoming_commitments); it may not write any state; prevents LLM performing financial actions per FR-7.2
- (decision) AD-11: SSE event schema as API contract — Copilot endpoint emits exactly three event types: {type:'token', text:string}, {type:'trace', sources:[...]}, {type:'done'}; no other event shape is valid; prevents client and server drifting on the streaming protocol per FR-7.4
- (decision) AD-12: parser failure is honest refusal not silent wrong data — any parsing error (scanned PDF, unrecognized layout, corrupt file) must surface a plain-language message to the user; silent wrong-row counts or empty results are forbidden; implements the fail-honest default per NFR-1, FR-2.4, FR-2.9
- (decision) AD-13: shared formatting utilities required — formatINR() (Indian number grouping ₹1,25,000) and formatDate() (ISO to '30 Jun 2026') are the only permitted currency and date display functions; non-standard formatting anywhere fails acceptance per NFR-7
- (decision) AD-14: services/ as Phase 2 migration boundary [ADOPTED] — because Reflex runs on FastAPI/Starlette already, extracting services/ to a standalone FastAPI service is a lift-and-shift; Phase 2 is a re-skin not rewrite only if this boundary holds; prevents business logic coupling into Reflex-specific APIs per NFR-6
